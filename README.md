# vida-framework
--------------------------------------------------------------------------
## Getting Started

Requires Unity 6 (6000.0) or later. Install the framework through Package Manager using its Git URL; declared package dependencies are installed automatically.

Use the new Input System. After installation, accept Unity's prompt to enable the new input backend, or set **Edit > Project Settings > Player > Other Settings > Active Input Handling** to **Input System Package (New)**, then restart the Editor. The package dependency alone does not change this project setting. Existing projects must migrate legacy `UnityEngine.Input` calls and UI input modules before using New-only mode.
